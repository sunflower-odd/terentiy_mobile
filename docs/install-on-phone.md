# Установка приложения на телефон

**Дата:** 6 октября 2026 года

Инструкция для того, кто получил файл `terentiy-1.0.apk`.

## Что понадобится

| | |
|---|---|
| Телефон | Android 8.0 или новее |
| Файл | `terentiy-1.0.apk` |
| Адрес сервера | например `http://192.168.0.42:8080` — узнать у того, кто поднял сервер |
| Код установки | оттуда же |
| Сеть | **телефон и машина с сервером в одной Wi-Fi**, машина включена |

**Приложение работает только внутри этой сети.** Вне её — дома у соседа, на
работе, на мобильном интернете — оно покажет «Устройство наблюдения не
отвечает». Это ожидаемо, а не поломка.

Разрешений приложение не просит: только доступ в интернет, он выдаётся при
установке молча. Ни камеры, ни геолокации, ни доступа к файлам.

---

## 1. Установить

**Просто открыть файл на телефоне** — скачать из мессенджера или облака и
нажать. Android спросит разрешение на установку из неизвестного источника,
подтвердить. Play Protect может назвать приложение непроверенным — для сборки,
собранной вручную, это ожидаемо.

**Или по кабелю**, если телефон подключён к компьютеру с Android SDK:

```bash
adb install -r terentiy-1.0.apk
```

Для этого на телефоне нужна отладка по USB: Настройки → О телефоне → семь раз
нажать «Номер сборки» → вернуться → Для разработчиков → Отладка по USB.

## 2. Проверить, что телефон видит сервер

До запуска приложения откройте в браузере телефона:

```
http://АДРЕС_СЕРВЕРА:8080/health
```

Должно вернуться `{"status":"ok","database":"ok"}`.

Не открывается — дело не в приложении, а в сети:

- телефон в другой сети или на мобильном интернете — переключить на ту же Wi-Fi;
- брандмауэр на машине с сервером блокирует входящие на 8080;
- сервер не запущен.

## 3. Подключить приложение

| Поле | Что вводить |
|---|---|
| Адрес сервера | `http://АДРЕС:8080` — обязательно со схемой и портом |
| Код установки | выданный вам |
| Имя | любое |
| PIN | шесть цифр, и повтор |

Кнопка **«Проверить адрес»** обращается к `/health` и отличает «сервер не
отвечает» от «код не подошёл» — нажмите её до подключения.

Дальше: главная со состоянием контура наблюдения, история падений, карточка
события с кадром, запись.

---

## Как телефон связывается с сервером

```
телефон  →  Wi-Fi роутер  →  машина с сервером:8080
```

Напрямую по локальной сети. Ни облака, ни внешнего сервера в цепочке нет, трафик
не покидает роутер.

## Если приложение не подключается

1. **`/health` в браузере телефона открывается?** Нет — проблема в сети, см. шаг 2.
2. **Адрес введён со схемой и портом?** `192.168.0.42:8080` без `http://` не подойдёт.
3. **Код установки не подошёл** — приложение скажет об этом отдельно от «сервер
   не отвечает». Уточните код у того, кто поднял сервер.
4. **Что-то другое** — передайте текст ошибки с экрана тому, кто выдал файл.

## Чего в этой сборке нет

- **Уведомлений при закрытом приложении.** Тревога о падении видна, только пока
  приложение открыто на экране. В фоне и при выключенном экране оповещения не
  придёт.
- **Работы вне домашней сети.**
- **Шифрования трафика.** Данные идут по локальной сети открытым текстом. Для
  проверочного стенда это допустимо, для постоянной установки — нет.
